# Listing Writer Pro

Landing page for the Real Estate Marketing Pro listing description writer at https://writer.realestatemarketing.pro.

The page frames the live Chatbot Builder agent full-screen so agents see the REMP domain. To change the bot itself (instructions, colors, knowledge), edit it in Chatbot Builder and click Publish Changes. Nothing here needs to change.
